# Etch-a-Sketch

A browser-based Etch-a-Sketch built with vanilla HTML, CSS, and JavaScript as part of The Odin Project.

## Features

- Generates a dynamic drawing grid using JavaScript
- Hover over cells to draw
- Adjustable grid resolution
- DOM manipulation and event-driven interactions

## Technologies

- HTML
- CSS
- JavaScript

## Future Improvements

- Random color mode
- Progressive darkening effect
- Click-and-drag drawing
- UI polish and animations
